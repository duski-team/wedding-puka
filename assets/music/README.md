# Music Files

Silakan tambahkan file musik pernikahan ke dalam folder ini:

## Format yang didukung:
- `wedding-music.mp3` (format utama)
- `wedding-music.ogg` (format alternatif)

## Cara menambahkan musik:
1. Pilih lagu instrumental romantis atau lagu pernikahan favorit Anda
2. Konversi ke format MP3 dengan kualitas yang baik (128-192 kbps)
3. Rename file menjadi `wedding-music.mp3`
4. Tempatkan file di folder ini

## Rekomendasi lagu:
- Instrumental piano atau guitar
- Lagu klasik pernikahan
- Instrumental dari lagu romantis
- Musik ambient yang lembut

**Catatan**: Pastikan Anda memiliki hak cipta atau lisensi untuk menggunakan musik tersebut.
